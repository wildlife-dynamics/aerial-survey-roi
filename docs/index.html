Aerial Survey ROI Workflow

Generates aerial survey transect lines over a user-defined Region of Interest (ROI), at a specified compass direction and spacing, and displays them on an interactive dashboard map.

Step-by-step instructions for loading, configuring, and running the workflow.

Troubleshooting

Common errors you may hit while configuring or running the workflow, and how to resolve them.

What it produces

  • An interactive HTML ecomap showing the survey lines overlaid on the ROI
  • The survey lines exported as a GeoParquet (.parquet)
  • A dashboard widget displaying the map

Note: This workflow only supports polygon geometry. Point and line geometry types are not supported.

Requirements

  • A geospatial boundary file (GeoPackage, GeoJSON, or GeoParquet) containing polygon or multipolygon geometry, reachable by URL or local path
  • No EarthRanger or Google Earth Engine connection is required for this workflow

Get started

New to the workflow? Start with the User Guide for a walkthrough of loading the template, configuring the ROI and survey lines, and running it. Running into an error? Check Troubleshooting first.
